# Changelog

## 1.0.1 — 2026-08-19

- Added a clean first-launch state with a compact unit-based example.
- Existing users' saved settings and calculation history continue to take priority.

## 1.0.0 — 2026-08-19

- First public release.
- Editable calculator history and report-friendly descriptions or units.
- Live number formatting, selectable grouping separator, and fractional-digit styling.
- List Mode with continuously recalculated series and previous-result continuation.
- Parenthesis completion, implicit multiplication, selection-aware functions, and mathematical symbols.
- Optional keypad, tray icon, always-on-top mode, font resizing, and Persian-layout shortcuts.
