# Changelog

## 1.1.0 — 2026-11-08

- Added a Windows executable release and a source launcher that checks dependencies.
- Added a selectable display font, main font size and independent fractional-digit size adjustment.
- Added separate × and ÷ symbol preferences and optional thin spacing around operators.
- Entered fractional digits are styled immediately to avoid a visible size change while typing.
- Reduced redundant formatting work during typing.
- Pasting from Excel removes one automatic trailing line break.
- Ctrl+Z restores the last cleared contents; three consecutive Escape presses minimize the window.
- Existing saved preferences and calculation history remain compatible.

## 1.0.1 — 2026-08-19

- Added a clean first-launch state with a compact unit-based example.
- Existing users' saved settings and calculation history continue to take priority.

## 1.0.0 — 2026-08-19

- First public release.
- Editable calculator history and report-friendly descriptions or units.
- Live number formatting, selectable grouping separator, and fractional-digit styling.
- List Mode with continuously recalculated series and previous-result continuation.
- Parenthesis completion, implicit multiplication, selection-aware functions, and mathematical symbols.
- Optional keypad, tray icon, always-on-top mode, font resizing, and Persian-layout shortcuts.
